# 撞號風險模組（方案A：規則式熱門倍數）

給 PWA「號碼」分頁的「跟別人撞號的風險」區塊使用。純 ES module，不需建置。

## 檔案
- `split-risk.js`：計算模組，主函式 `analyzeCombo(nums, { jackpot, sales, lastDraw })`
- `split-risk.test.mjs`：測試，執行 `node --test split-risk.test.mjs`
- `demo.html`：示範頁（需用本機伺服器開啟，例如 `npx serve .`）

## 計算方式
1. 熱門倍數 = 電腦選號比例 × 1 + 人工選號比例 × (這組特徵分數 ÷ 全部組合平均分數)
2. 其他同組注數 λ = 預估注數 × 熱門倍數 ÷ 13,983,816
3. 中頭獎時平均分到比例 = (1 − e^−λ) ÷ λ（卜瓦松分布）
4. 每注稅後期望值 = 固定獎 14.57 + 貳～肆獎 1.92 + 頭獎 × 79.6% × 分獎比例 ÷ 13,983,816

## 估計值（非官方，需在畫面標示）
- 特徵權重見 `WEIGHTS`，為人工設定
- 電腦選號比例假設 50%（未查到官方數字）
- 下期銷售額需由資料流程估算或手動輸入
- 貳～肆獎未計入熱門度造成的分獎
- 選號單上排成直線的特徵尚未納入：官方選號單版面還沒查證
